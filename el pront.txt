Guía Técnica de Modelado en Blender: Despiece Isométrico CEDI 360

Esta guía contiene la formulación completa para implementar el camión logístico y contenedor modular en Blender:





Árbol de Geometry Nodes para generación automática de líneas de cotas, guiones y proyecciones paramétricas.



Dimensionamiento Normalizado 1:1 en metros para chasis, cabina, contenedor ISO 40ft High Cube y componentes de telemetría.



PARTE 1: Sistema Paramétrico de Cotas y Proyecciones con Geometry Nodes

En Blender, este árbol de nodos se aplica sobre curvas Bézier o aristas de malla para generar de forma procedural los trazos punteados de despiece, flechas en los extremos y marcas de medición con textos flotantes.

1.1 Configuración de Nodos para Líneas Punteadas (Dashed Projection Lines)

Para que las líneas de proyección entre capas (desde el chasis hasta el techo flotante) mantengan un patrón punteado consistente sin importar la longitud de la separación:

[Group Input (Curve)] 
        │
        ▼
[Curve to Mesh] ──(Profile Curve: Circle r=0.003m) 
  o alternativamente:
[Resample Curve] ──(Mode: Length, Length: 0.08m)
        │
        ▼
[Trim Curve] ──(Start: 0.0, End: 0.5) 
  * Esto crea tramos cortados equivalentes a guiones punteados.
        │
        ▼
[Curve to Mesh] ──(Profile: Line / Circle r=0.004m)
        │
        ▼
[Set Material] ──(Material: "M_CAD_LeaderLine_Cyan" / Color #7FB0FF con Emission 2.5)
        │
        ▼
[Group Output]

1.2 Nodos para Flechas y Topes de Cota (Leader Dimension Endpoints)

Para colocar marcadores técnicos en los extremos de las cotas:





Agrega el nodo Endpoint Selection conectado a un nodo Instance on Points.



Conecta una malla de cono o cruz en el zócalo Instance (escala 0.025m).



Conecta el vector tangente de la curva (Curve Tangent) al nodo Align Euler to Vector (eje Z o X según la orientación de la flecha) y conéctalo a la rotación de las instancias.

1.3 Texto de Cota Automático en Billboard (HUD Text)

Para que el rótulo con la medida (ej. "L: 12.192 m") siempre mire hacia la cámara isométrica:





Usa el nodo String to Curves.



Convierte la longitud calculada con Curve Length mediante Value to String (Decimals: 2 o 3).



Agrega un modificador / constraint de objeto Track To o Copy Rotation hacia la cámara (Cam_Isometric_Master), asegurando que las anotaciones nunca se distorsionen en perspectiva.

PARTE 3: Parámetros de Animación del Despiece por Controladores (Drivers)

Para automatizar el despliegue de las capas con una sola curva de animación:

# Asignación de desplazamientos relativos al Empty "MASTER_DESPIECE" (valor Z de 0.0 a 1.0)
Techo_Fase3.location.z = Z_base + (MASTER_Z * 2.80)     # Elevación 2.80 m
Carga_Fase1.location.z = Z_base + (MASTER_Z * 0.50)     # Flotación 0.50 m
Pared_Izq.location.x   = X_base - (MASTER_Z * 1.60)     # Desplazamiento lateral 1.60 m
Pared_Der.location.x   = X_base + (MASTER_Z * 1.60)     # Desplazamiento lateral 1.60 m
Puerta_Izq.rotation.z  = Rot_base + (MASTER_Z * 135)    # Apertura 135 grados
Puerta_Der.rotation.z  = Rot_base - (MASTER_Z * 135)    # Apertura 135 grados
